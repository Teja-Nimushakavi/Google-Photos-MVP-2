# Deployment Guide (Railway + Vercel)

This guide explains how to deploy the Smart Suggestions MVP, with the **Backend hosted on Railway** and the **Frontend hosted on Vercel** via GitHub integration.

## 1. Push Code to GitHub
Ensure your local git repository is pushed to a GitHub repository.

## 2. Deploy Backend (FastAPI) to Railway
1. Go to your [Railway Dashboard](https://railway.app/dashboard).
2. Click **New Project** -> **Deploy from GitHub repo** and select your repository.
3. Railway will ask you to select a root directory or deploy the whole repo.
   - Click on the newly created service card in Railway.
   - Go to **Settings** -> **Deploy** -> **Root Directory**.
   - Type `/backend` and save. Railway will use the `railway.toml` inside this directory to build and deploy the FastAPI app.
4. Add the required environment variables:
   - Go to the **Variables** tab for the backend service.
   - Add `GEMINI_API_KEY = "your_actual_api_key_here"`.
   - Add `DATA_DIR = "/data"` (this tells the app to store data in the persistent volume).
5. Attach a Persistent Volume for ChromaDB:
   - Go to the **Volumes** tab in your project dashboard (or within the service settings) and create a New Volume.
   - Attach it to the backend service and set the Mount Path to `/data`.
6. Once deployed, go to the **Settings** tab and click **Generate Domain** under the Public Networking section. This will be your `BACKEND_URL` (e.g., `https://backend-production.up.railway.app`).

## 3. Deploy Frontend (React Native Expo) to Vercel
1. Go to your [Vercel Dashboard](https://vercel.com/dashboard).
2. Click **Add New...** -> **Project** and import your GitHub repository.
3. Configure the Project:
   - **Framework Preset**: Vercel might auto-detect "Create React App" or "Other". 
   - **Root Directory**: Click "Edit" and select `frontend`.
   - **Build Command**: Override to `npx expo export -p web`
   - **Output Directory**: Override to `dist`
4. Add Environment Variables:
   - Name: `EXPO_PUBLIC_API_URL`
   - Value: `https://your-generated-backend-domain.up.railway.app` (The domain you generated in Step 2.6. Make sure there is no trailing slash).
5. Click **Deploy**. Vercel will build the Expo web application and provide you with a production URL.

## 4. Final Testing
1. Visit the frontend domain generated by Vercel.
2. The UI should load successfully and communicate with your backend on Railway.

> Note: If you need to populate the database with images on Railway, you might need to upload or sync your `photos_dataset.json` and images to the volume `/data` on Railway, or trigger the backend's data ingestion script after deployment.
